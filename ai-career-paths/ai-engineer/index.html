AI engineer

Builds LLM products that act and answer from an organization's own data. Agents plan, call tools and recover over many steps; retrieval grounds them in documents, tickets, code and records. Most postings ask for both, so this path covers both: one shared trunk that splits into an agent branch and a retrieval branch. The work is engineering reliable loops, context, retrieval quality, evals and guardrails around provider APIs, not training models.

Defining stack: Agents · RAG · Prompt engineering · Vector databases · LangChain / LangGraph

Other paths: Cloud / ML platform engineer · DevOps / full-stack engineer · ML trainer / researcher

Step 6Capstone

Grounded ops agent capstone

Build an operations agent over three or more real tools (tickets, docs, chat) using MCP and a sandbox, plus a hybrid-search retrieval tool with a reranker over a messy real corpus. Back it with a 50-case eval suite covering task success, recall@k and citation accuracy, and report which change moved each number.
