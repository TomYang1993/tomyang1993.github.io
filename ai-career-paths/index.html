AI Career Path Map

Five 2026 AI role archetypes and the skills each one needs. Every skill box carries three layers: university courses, free hands-on projects, and the foundational papers behind it.

Role shares and defining stacks come from the archetype breakdown this map starts from. Courses and projects were checked against their live pages in November 2026; whether lecture videos are public changes from term to term, so each course is tagged with what is open right now. Every project listed is free (some cost GPU time to run). Many courses and projects span several boxes: each card lists the others it covers. Transition graphs assume a typical skill set for each starting job; if you lack a box marked as covered, treat it as part of the bridge. Tools are the common choices in postings, not endorsements.
