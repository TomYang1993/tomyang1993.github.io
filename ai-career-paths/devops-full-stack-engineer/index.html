DevOps / full-stack engineer

Builds and ships the product around the model: React frontends, APIs, CI/CD and Kubernetes. Not every posting is AI-first, but AI features and coding agents are a growing part of the job, and the hop into agent building is short.

Defining stack: CI/CD · Kubernetes · React / frontend

Open this path on the interactive mapMinimal steps on GitHub

Other paths: AI engineer · Cloud / ML platform engineer · ML trainer / researcher

The path at a glance

  1. Step 1 · Foundations

  2. Step 2 · Core
    LLM APIs & prompt engineering · AI product frontend · Containers & CI/CD
  3. Step 3 · Building blocks
    AI-native development · Kubernetes & multi-cloud · Evals & observability
  4. Step 4 · Applied
    Testing & observability · MLOps & AI in production
  5. Step 5 · Capstone

Step 1Foundations

1.1 Python & engineering craft

Async, type hints, tests and Git as daily habits.

Every archetype ships Python. Async code, type hints, tests and a clean Git workflow are table stakes before anything AI-specific.

Also on the path for: AI engineer, Cloud / ML platform engineer, ML trainer / researcher

Skills

  • Type hints and Pydantic models
  • Packaging and virtual environments
  • Unit and integration testing

Step 5Capstone

Full product capstone

Ship a streaming AI feature end to end (Next.js UI, API, model provider) with evals as a CI merge gate, preview deploys and a tested rollback path.

Follow along

  • AI Dev Tools ZoomcampDataTalks.Club, free. Modules 2–4 build one full-stack app and take it through tests, Docker, a public deploy, GitHub Actions CI/CD and observability; the final project asks for CI/CD with a rollback path.
  • AI SDK RAG templateVercel, free. A Next.js chat app that streams model responses and retrieves from Postgres through tool calls; deployed on Vercel, every pull request gets a preview deploy.
  • promptfoo GitHub ActionFree and open source. Runs your eval suite on every pull request and fails the check below a pass rate; make that check required and evals become the merge gate.
