Pulse

Pulse is a personal command-line tool for managing my own YouTube channels. It runs only on my own computer. It is not a public service, and nobody else can sign up for it.

When I sign in with Google, Pulse uses the YouTube Data API and YouTube Analytics API to:

  • upload videos and thumbnails to my channels
  • edit video titles, descriptions and other details
  • read channel and video statistics, including revenue where a channel has it

See the privacy policy for how this data is handled.
